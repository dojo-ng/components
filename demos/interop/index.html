The same app, four hosts

Nobody expects MUI to run in Angular, or Ant Design in Vue. Component kits are married to their framework. Dojo NG components are custom elements, so the member-signup card below runs identically in plain HTML/JS, the @dojo-ng/framework renderer, React 19, and Vue 3. Each host passes the role options as an array property, hears the components' bubbling CustomEvents, submits through the native form, and shares one theme and one locale mechanism. Submit the form in any frame; the printed FormData is the same in all four.

The React and Vue frames load their runtimes from esm.sh and need network access. Serve from the components root (npm run serve), then open /demos/interop/.

plain.html — vanilla JS

framework.html — @dojo-ng/framework renderer

react.html — React 19 + htm, no JSX build

vue.html — Vue 3 esm-browser, in-browser templates
