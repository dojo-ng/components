# @dojo-ng/i18n

Dojo NG internationalization: locale signal, Intl formatting, message resolver, pluggable loader

Part of [Dojo NG](../../README.md), a framework-agnostic web component library. BSD-3-Clause.

## Install

```bash
npm install @dojo-ng/i18n
```

## Usage

See the [Dojo NG documentation](../../README.md) (i18n-guide.md) for design and usage details.
