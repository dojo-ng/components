Navigation history — tracked tree, tracked cards, back button

The tree is the menu, the cards are links, and the view on the right is chosen only from the published location. Skim a few pages quickly, wait for the dwell to pass on the last one, then press Back: the skimmed pages are skipped. Cmd/Ctrl-click a card or a tree row to open it in a new tab.

Server note: this playground is served by python3 -m http.server, which has no SPA fallback. The demo runs under the page's own URL (base is set to this file's path), so Back, Forward and trail work, but reloading on a deep path such as /playground/nav-history-demo.html/orders/7 returns 404. Deep-path reload is demonstrated in the history package's own playground (framework/packages/history/playground), which does serve every route.
